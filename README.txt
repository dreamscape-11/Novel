# TIME KILLER

모바일 브라우저에서 실행하는 개인용 미니게임 웹앱입니다.

## 실행
- `index.html` 파일을 브라우저에서 열면 실행됩니다.
- GitHub Pages에 게시하려면 저장소 최상위 폴더에 `index.html`을 올린 뒤 Settings → Pages에서 배포 브랜치를 선택하세요.

## 포함 게임
- 숫자 합치기 2048
- 오늘의 단어
- 반응 속도 테스트
- 끝없는 던전
- 방치형 상점

## 저장과 백업
게임 기록은 브라우저의 localStorage에 자동 저장됩니다.
설정 메뉴에서 JSON 백업 파일을 내보내거나 복원할 수 있습니다.
브라우저 데이터 삭제 전에는 백업을 권장합니다.

현재 버전은 싱글 플레이 기반이며 온라인 계정 동기화 기능은 포함하지 않습니다.
